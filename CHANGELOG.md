# Změny

## 1.0.0 – 2026-11-04
- První verze růžové edice Klida.
- Vstupní dotazník (oslovení, rod, témata, nálada, spánek, styl odpovědí, bezpečí) uložený jen v prohlížeči.
- Nulová paměť: rozhovor jen v paměti serveru, `--no-session-persistence`, Claude bez nástrojů a bez přístupu k souborům.
- Tlačítko „Je mi zle teď“, krizové kontakty (116 123, 155, 112, 116 111) a automatické přepnutí na silnější model v těžkých chvílích.
- Tmavý a světlý růžový režim, 3D koule.
- Instalace přes Claude Code (`INSTALL.md`), kontrola `npm run check`, spouštěče pro Mac a Windows.
